# House-Price-prediction

Built a simple House Price Prediction project using Python and Machine Learning during my AI/ML internship at [Acadeno Technologies Private Limited](https://www.acadeno.com?utm_source=chatgpt.com) 🚀

In this project, I used:
• Pandas for data handling
• Scikit-learn for model training
• Linear Regression, Ridge, and Lasso algorithms
• StandardScaler for feature scaling

The model predicts house prices based on:
🏠 Living Area
🛏 Number of Bedrooms
🛁 Number of Bathrooms

Also compared model performance using R² Score and tested predictions with custom user inputs.
